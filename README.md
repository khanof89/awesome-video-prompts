## Prompt Structure

Each prompt in this repository follows a structured format:

```
[Scene Description]
[Camera Movement]
[Visual Style]
[Additional Effects]
[Duration]
```

Example:

```
A serene mountain landscape at sunset, with a flowing river in the foreground
Wide establishing shot, 24mm lens, slow pan from left to right
Cinematic, high contrast, warm color grading
Light fog and lens flare
10 seconds
```

## Lens & Framing Cheat Sheet

Text-to-video models respond best to **shot size + focal length**. Shot size ("close-up", "wide shot") sets the framing, and the lens sets perspective and depth of field. Use both in the camera line.

| Lens | Typical use | Look |
| ---- | ----------- | ---- |
| 14-24mm | Establishing shots, landscapes, interiors, aerials | Wide field of view, exaggerated depth, edge distortion |
| 28-35mm | Documentary, street, tracking shots | Natural, immersive perspective |
| 50mm | Medium shots, general purpose | Close to human vision, neutral |
| 85mm | Portraits, fashion, close-ups | Flattering compression, soft background |
| 100mm macro | Food, products, extreme close-ups | Tiny details, razor-thin focus |
| 135-200mm+ | Wildlife, sports, distant subjects | Strong compression, heavy background blur |
| 8-16mm fisheye | Action sports, stylized shots | Extreme curvature, dynamic energy |

Tips:

- Pair a shot size with a lens, for example `Extreme close-up, 100mm macro lens`. Millimeters alone don't set framing.
- Treat mm values as a style cue. Results vary between models and are weakest for animated or abstract styles.
- Keep one lens per shot, and change it only when the shot changes.
